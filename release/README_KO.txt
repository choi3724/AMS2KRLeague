AMS2 League Overlay 0.7.3
============================================

빠른 시작
1. AMS2 옵션 → 시스템 → 공유 메모리에서 Project CARS 2를 선택합니다.
2. AMS2LeagueClient.exe를 실행합니다.
3. 모니터에서 사용할 때는 게임을 테두리 없는 창 또는 창 모드로 실행합니다.

별도 .NET 설치나 토큰 입력은 필요하지 않습니다.
상태창에서 게임 연결과 서버 전송 상태를 확인할 수 있습니다.

화면 설정
- 표시할 오버레이를 선택하고 레이아웃 편집으로 위치와 크기를 조절합니다.
- 게임 없이 주행 UI 편집 / 게임 없이 대기 UI 편집으로 게임 실행 전에도 배치를 바꿀 수 있습니다.
- 미리보기 데이터를 보며 조절한 뒤 저장하고 잠금을 누릅니다.
- 색상·글꼴·핸들 설정에서 입력 그래프 색상, 속도·기어 글꼴과 각각의 그림자 색상을 바꿀 수 있습니다.

VR 표시 (시험 지원)
- SteamVR와 헤드셋을 연결한 뒤 AMS2를 SteamVR로 실행합니다.
- 모니터·VR 표시 설정에서 모니터 / VR / 동시 표시를 고릅니다.
- 화면 위치·크기·거리·각도, 고개 추종·공간 고정을 설정할 수 있습니다.
- 실제 헤드셋에서의 표시와 성능 검증은 진행 전입니다.
- Meta/Oculus 또는 OpenXR 단독 실행은 현재 지원하지 않습니다.
- VR 사용을 마치려면 표시 설정을 모니터로 바꿉니다.

기록 전송
- 확인된 멀티플레이 기록을 로컬에 보관하고 서버로 전송합니다.
- 연습·예선·레이스 기록은 전체 레이스 종료 후 모아서 전송합니다.
- 싱글플레이와 모드 미확인 기록은 로컬에만 보관합니다.
- 서버가 지원하면 기록을 압축해서 전송합니다. 기록 내용은 유지됩니다.
- 오프라인으로 전송하지 못한 기록은 연결이 복구되면 다시 전송합니다.

자동 업데이트
새 버전을 자동으로 확인하고 업데이트 후 프로그램을 다시 실행합니다.
게임을 종료할 필요는 없으며, 업데이트 중 오버레이 표시와 수집은 잠시 중단됩니다.
설정과 기존 기록은 유지됩니다.
0.4.0 이하 버전은 0.7.3을 한 번 수동 설치해야 합니다.

데이터와 로그 위치
%LOCALAPPDATA%\AMS2KRLeague
%LOCALAPPDATA%\AMS2KRLeague\logs

제거
- 설치판: Windows 설정 → 앱 → AMS2 League Overlay 제거
- 포터블: 압축을 푼 폴더 삭제
- 설정과 기록은 별도로 보관됩니다.
