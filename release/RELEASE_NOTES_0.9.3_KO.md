# AMS2 리그 오버레이 0.9.3

## 기능 추가
- 게임 없이 UI를 편집할 때 각 오버레이를 우클릭하면 해당 설정 페이지를 열 수 있습니다. 글꼴, 글자 크기, 디자인과 관련 색상을 바꾸는 즉시 미리볼 수 있습니다.
- 오버레이를 한 단계씩 앞뒤로 이동하거나 맨 앞·맨 뒤로 배치할 수 있습니다. N 계기판도 겹침 순서를 조절할 수 있으며 저장한 순서는 다시 실행해도 유지됩니다.

## 버그 수정
- 설정을 취소하면 미리보기 중 바꾼 모양과 겹침 순서가 원래대로 돌아가도록 수정했습니다.
- 오버레이를 이동하거나 크기를 바꾼 뒤 겹침 순서가 다시 바뀌는 문제를 수정했습니다.
