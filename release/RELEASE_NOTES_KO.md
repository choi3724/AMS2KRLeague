# AMS2 리그 오버레이 0.8.1 업데이트

- 0.8.0에서 일부 HUD의 투명 영역이 회색 또는 흰색 직사각형으로 나타나던 문제를 수정했습니다. 기본 모니터 표시를 기존 픽셀 투명 WPF 경로로 복구했습니다.
- `--monitor-glass`와 `--monitor-retained-n`은 명시적으로 요청할 때만 동작하는 실험 옵션으로 유지합니다. `--monitor-layered`가 우선합니다.
- HUD 위치·RPM 정책과 데이터 수집·기록·전송 계약은 변경하지 않았습니다.
- 확장형 N 계기판의 연료·냉각수 막대가 원본의 경사진 테두리 안에 맞도록 수정했습니다. 냉각수 막대는 관측 온도에 따라 움직이며, C/H는 화면 표시용 40~120°C 범위입니다. 차량 경고 기준은 아닙니다.
- 연료·냉각수 막대의 일부만 찼을 때도 채워진 길이 전체에 파란색→흰색 그라데이션이 나타납니다. 글꼴 두께와 상태 표기를 조정하고 전조등 상태, 공식 현대 N 로고를 추가했습니다.
- ABS·TCS가 켜져 있으면 노란색, 실제 ABS 작동 또는 스로틀 제한으로 추정되는 TCS 작동 중이면 빨간색으로 표시합니다. TCS 작동 표시는 게임 SHM에 직접 신호가 없어 추정값입니다.
- N 계기판 모드를 켤 때 바깥쪽 불꽃과 안쪽 파란 링이 한 번 나타났다 사라집니다. 계기판 바늘·RPM 변화와는 별개의 연출입니다. 불꽃은 새 투명 이미지 자산을 사용하며, 모드를 잠시 숨겨도 재생을 반복하지 않습니다.
- 기존 WPF 경로의 고부하 프레임 지연은 해결되지 않았습니다. Monitor 성능은 RED이며 실게임·VR·트리플 모니터에서 이 수정본의 화면 결과는 아직 검증 전입니다.
