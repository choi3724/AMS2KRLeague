# AMS2 리그 오버레이 0.7.4 업데이트

### 개선사항

- 트리플 모니터 사용 시 UI 배치 관련 사항 개선
- 좌측·상단 화면의 음수 좌표와 게임 창 이동에 따른 배치를 처리합니다.
- 배치 저장·복원 기준을 유지하고, 모니터가 일시적으로 빠져도 원래 저장 위치를 덮어쓰지 않습니다.

- 싱글·듀얼·트리플 좌표 구성의 자동 검사와 연결된 두 모니터의 WPF 배치·저장·복원을 검증했습니다.
- 물리 트리플·혼합 DPI·모니터 재연결·실게임·VR 실기기 검증은 NOT TESTED입니다.
- 프레임 끊김 해결을 포함한 업데이트가 아닙니다. 기존 Monitor 성능 RED를 유지합니다.
- N 계기판 RPM 정책·폰트·이미지와 수집·기록·전송 동작은 유지합니다.
