# AMS2 리그 오버레이 0.8.4 업데이트

- 게임 중 모든 HUD가 0.2~0.5초마다 뚝뚝 끊기던 문제를 줄이기 위해 HUD를 GPU 대신 CPU로 그리도록 바꿨습니다. 게임이 GPU를 모두 사용할 때 HUD가 GPU 순서를 기다리며 멈추는 구조를 피합니다.
- 게임 데이터 읽기를 전용 스레드로 옮기고, 계기판·페달 값 읽기가 게임의 데이터 갱신과 겹쳐도 같은 프레임에서 다시 읽도록 했습니다.
- 모든 HUD가 값이나 움직임이 바뀔 때만 다시 그리도록 했습니다. 게임이 새 데이터를 주지 않았거나 순위표 내용이 같으면 다시 그리지 않습니다.
- N 계기판 창은 시작 연출 중에만 불꽃 영역까지 크게 쓰고, 평소에는 계기판 크기로 줄여 그리는 양을 줄였습니다. 저장한 위치와 크기는 그대로입니다.
- 색상·글꼴·핸들 설정에 "HUD 프레임 제한"을 추가했습니다. HUD를 1초에 최대 몇 번 그릴지 30~240 FPS 사이에서 1 FPS 단위로 정할 수 있고 기본은 60 FPS입니다. 높을수록 부드럽지만 그만큼 CPU를 더 사용합니다.
- 문제가 생기면 AMS2LeagueClient.exe를 --monitor-hardware 인자로 실행하면 0.8.3의 GPU 표시 방식으로 돌아갑니다.
- 기록 수집·전송 방식은 바뀌지 않았습니다.
- 실제 게임에서의 효과는 아직 검증 전입니다. Monitor 성능 상태는 RED입니다.

# AMS2 리그 오버레이 0.8.3 업데이트

- 간결 N 계기판의 상단 테두리가 원형을 따라 끝까지 이어지도록 수정했습니다.
- 기어 숫자 양옆의 차폭등·하향등 표시와 km/h의 위치를 사용자가 편집한 계기판 참조 이미지에 맞췄습니다.
- 확장형 연료·냉각수 게이지의 유리 표면 안에 25·50·75% 눈금을 추가했습니다.
- 기본 WPF와 명시적 시험용 --monitor-retained-n 경로를 함께 수정했습니다. 기존 수집·기록·전송 계약은 유지합니다.
- 실제 게임·VR·물리 트리플 모니터의 화면 및 성능은 검증 전입니다. Monitor 성능 상태는 RED입니다.
