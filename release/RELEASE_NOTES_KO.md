# AMS2 리그 오버레이 0.7.1 업데이트

### 기록 저장 및 전송

- 서버 응답에 오류가 있거나 저장 여부가 불분명할 때, 전송 완료로 처리하지 않고 다시 전송하도록 수정했습니다.
- 서버 인증 오류가 발생하면 자동으로 연결을 복구하고 기록 전송을 재시도합니다.
- 멀티플레이 판정이 늦게 확인된 기록도 전송 대기 상태에서 이어서 처리하도록 개선했습니다.
- 종료 기록이 저장됐는데도 업로드가 계속 대기하던 문제를 수정했습니다.
- 예기치 않은 종료 뒤 새로 저장한 기록의 전송 정보를 복구하는 처리를 보강했습니다.
- 기록 저장 실패가 반복될 때 발생하던 불필요한 처리 부하를 줄였습니다.

### 주행 화면

- 게임 데이터를 잠시 읽지 못했을 때 텔레메트리 그래프 전체가 지워지던 문제를 수정했습니다.
- 표시하지 않는 오버레이의 불필요한 갱신을 줄이고, 그래프와 계기판의 그리기 처리를 개선했습니다.
- 로그 저장과 프로그램 종료 처리로 화면이 멈추는 현상을 줄였습니다.

### 자동 업데이트

- 연습·예선·레이스가 진행 중일 때는 설치를 미루고, 경기 기록 저장이 끝난 뒤 업데이트하도록 변경했습니다.

### VR 안내

- VR 실기기 검증은 아직 진행하지 않았습니다. Quest 3 / Virtual Desktop 환경도 포함됩니다.
