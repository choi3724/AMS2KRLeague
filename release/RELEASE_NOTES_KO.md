# AMS2 리그 오버레이 0.4.3 — 타워 자동 높이 · 게임 실행 중 업데이트

## 변경
- 순위 타워의 베스트랩 상태 ‘최고’를 ‘최고속 랩’으로 변경했습니다.
- 참가자가 적으면 타워 배경과 실제 표시 창 높이가 자동으로 줄어듭니다. 인원이 늘면 저장된 최대 행 수까지 복원합니다. 최소 2행 공간을 유지하며 가로 폭·글꼴·다른 패널 배치는 유지합니다.
- 게임을 켜둔 상태에서도 업데이트합니다. 검증된 설치 파일을 준비한 뒤 기록을 정상 저장하고 오버레이만 종료·설치·백그라운드 재실행합니다. 게임과 다른 앱은 강제 종료하지 않습니다.
- 기존 해시·크기 검증, 설치 잠금, 취소 및 오류 처리, 같은 설치 경로의 중복 실행 방어를 유지합니다.

## 설치와 호환
- AMS2-League-Overlay-0.4.3-Setup.exe 또는 AMS2-League-Overlay-0.4.3-win-x64.zip.
- 이미 실행 중인 0.4.1~0.4.2는 기존 업데이트 코드 때문에 최초 0.4.3 자동 설치 시 게임 종료를 기다립니다. 0.4.3부터 이후 업데이트에 게임 종료가 필요하지 않습니다.
- 0.4.0 이하는 0.4.3 수동 설치가 필요합니다.
- 업데이트 중 오버레이 표시·기록 수집에 짧은 공백이 있습니다. 기록을 무중단 수집한다고 보장하지 않습니다.
- 0.4.2의 자동 모드 판정·멀티 확인 구간 전송을 유지합니다. 로그 부족·세션 경계의 UNKNOWN 보류와 운영 서버의 새 모드 헤더 저장 미검증 제한도 유지됩니다. 서버/DB 변경 없음.
