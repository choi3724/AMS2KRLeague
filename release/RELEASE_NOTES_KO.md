# AMS2 League Overlay 0.4.0 — 최고 랩 / 아웃랩 / PIT / UI 및 저장 안정화

사용자 요청 `0.4`를 기존 SemVer 형식 `0.4.0`으로 게시합니다. GitHub **Latest**, Pre-release 아님. 기존 릴리스와 안정 기준선 `v0.2.2`는 변경하지 않습니다.

## 주요 변경

- 순위 타워는 각 참가자의 **AMS2 최고 랩 기록**을 표시합니다. 실시간 관측 타이머나 `L` 직전 랩 접두사로 대체하지 않습니다.
- 연습·예선에서 기록이 없으면 **아웃랩 → 랩 타임 주행 중 → 인정된 최고 기록** 순서입니다. 이미 최고 기록이 있으면 다음 주행에도 유지합니다.
- 첫 계측 시작에 랩 번호가 증가하지 않는 경우, NotStarted로 보고되는 아웃랩, 일시정지/메뉴 전환 후 출차 이력이 사라지는 문제를 수정했습니다.
- 레이스 첫 바퀴는 아웃랩, 두 번째 바퀴는 레이스 중, 두 번째 바퀴 완료 이후 유효한 최고 기록을 표시합니다. 시작 전 잘못된 무효 알림을 억제하고 실제 랩 무효 신호는 개인 타임 고정과 이벤트로 알립니다. 기존 유효 최고 기록은 무효 처리하지 않습니다.
- PIT 배지 누락을 보완하고 전후방 후보를 피트/트랙별로 분리했습니다. 피트에서는 가까운 같은 영역 차량의 월드 직선거리(`~Nm`), 트랙에서는 진행거리를 사용합니다.
- 시간차와 LAP 표시 칸을 유지하되 연습·예선에서는 LAP 차이를 표시하지 않습니다. 선택 차량에 맞는 게임 split이 없으면 시간을 추정하지 않고 `—`로 표시합니다.
- 패널 가로·세로는 독립적으로 조절하면서 **글꼴 비율은 유지**합니다. Race Control 화면용 히스토리를 숨기고 현재 메시지를 크게 표시하며, 새 이벤트에도 플래시 효과를 적용합니다.
- 대기 화면에 자유 연습·예선·레이스를 구분하고 싱글/멀티 표시 선택을 추가했습니다. 싱글/멀티는 자동 감지가 아니며 UI 전용입니다.
- 잘못된 Story 거리로 인한 저장 실패, 실패 청크의 다른 스트림 차단, 부분 저장 후 재시도 문제를 보완했습니다. 403은 성공이나 무한 재시도로 처리하지 않고 정제된 진단과 격리 상태를 남깁니다.

## 검증 범위

- 릴리스 직전 전체 Release build와 Client/Activity 테스트, 공개 패키지 금지 항목 검사를 실행합니다. 실패하면 게시하지 않습니다.
- 아웃랩 수정은 실제 표시 데이터 946 snapshots / 27,309행 관측 재생에서 표시 불일치 0건, 아웃랩→계측 10회 / 계측→인정 기록 12회로 검증했습니다. 전체 raw 세션 재생이나 최종 인게임 시각 검수를 뜻하지 않습니다.
- 앞선 실제 멀티플레이 테스트에서 공개 Compact 36/36개의 서버 GET/decode 및 압축 해제 내용 hash 일치를 확인했습니다. 일부 gzip 포장 바이트는 달랐습니다. 이는 이전 수정 후보의 증거이며 이번 릴리스의 신규 서버 테스트는 아닙니다.

## 남은 제한과 안전 경계

- Compact Protocol/schema/cadence 및 private Driver 업로드 권한은 유지합니다. Cafe24 운영 파일/API/DB는 이번 릴리스에서 배포하거나 변경하지 않습니다.
- 관측 cadence 손실은 PARTIAL로 유지합니다. 세션 종료 경계의 짧은 추가 capture와 전환 분류 문제는 후속 과제이며, 과거 403 격리 항목을 자동 재전송하지 않습니다.
- 게임 부하에서 오버레이 출력 120 FPS 이상을 보장하지 않습니다. 피트 계산은 근거리 좌표 보조 방식으로 곡선/분기 전체의 피트 경로 복원이 아닙니다.
- SHM이 제공하지 않는 구체적인 트랙 리미트 사유, 공식 시간, 시간차를 임의로 만들지 않습니다.
- 코드 서명 인증서가 없어 SmartScreen 경고가 표시될 수 있습니다.
