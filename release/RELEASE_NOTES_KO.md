# AMS2 리그 오버레이 0.8.2 업데이트

- N 계기판이 게임 화면에 처음 나타날 때 바깥·안쪽 불꽃과 파란 링이 함께 한 번만 돌아가도록 수정했습니다. 바늘과 RPM 변화에는 연동하지 않습니다.
- 불꽃 바깥쪽까지 보이도록 투명 출력 영역을 넓히고 원의 중심·각도와 하단 패널의 가림 영역을 조정했습니다. 기존에 저장한 N 계기판 위치와 크기는 새 출력 영역에 맞춰 변환합니다.
- 확장형 연료·냉각수 막대의 원본 잔상을 가리고 반투명 채움과 테두리를 정리했습니다.
- 하단 연료량과 주행거리의 숫자·단위 글꼴을 조정하고, 두 숫자의 높이를 N 로고와 같은 세로 줄에 맞췄습니다.
- 기본 WPF와 명시적 시험용 `--monitor-retained-n` 경로를 함께 수정했습니다. 기존 수집·기록·전송 계약은 유지합니다.
- 실제 게임·VR·물리 트리플 모니터의 화면 및 성능은 검증 전입니다. Monitor 성능 상태는 RED입니다.
