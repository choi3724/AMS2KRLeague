# AMS2 리그 오버레이 0.4.1 — 한글 안내 · 페널티 · 자동 업데이트

## 변경

- FINAL/FIN을 완주로 표시하고 타워 상태, 랩 안내, 데모, 오류와 설치 안내를 한글화했습니다. 차량·트랙·클래스 고유 명칭과 P/S1 등의 순위·섹터 기호, 단위는 유지합니다.
- 타워 오른쪽에 페널티 열을 추가했습니다. AMS2가 보고한 드라이브스루, 스톱 앤 고, 실격을 표시합니다. 완주·피트·최고기록 상태와 동시에 표시하며, 의무/수리 피트를 페널티로 오인하지 않습니다. 시간 가산과 사유를 추정하지 않습니다.
- 타워 기본 폭 648px, 높이 608px. 기존 저장 폭은 확장 비율을 적용하며 다른 저장 패널은 그대로 유지합니다.
- 실행 시와 6시간마다 GitHub Latest 버전을 확인하고 새 설치 파일을 자동 다운로드합니다. 크기와 SHA-256이 모두 일치해야 설치합니다. AMS2 실행 중에는 설치를 미루고, 게임 종료 후 기록을 저장하고 프로그램을 정상 종료하여 같은 폴더에 설치한 뒤 재실행합니다.
- 업데이트 결과는 상태창과 `%LOCALAPPDATA%\AMS2KRLeague\updates`에 기록합니다. 실패 시 무한 재시작하지 않고 6시간 후 재확인합니다. Windows 자동 재부팅과 다른 앱 강제 종료는 금지합니다.

## 설치와 제한

- `AMS2-League-Overlay-0.4.1-Setup.exe` 또는 `AMS2-League-Overlay-0.4.1-win-x64.zip`.
- 0.4.0 이하에서는 최초 0.4.1 수동 설치가 필요합니다. 이후 자동 업데이트 대상이 되며, 새 GitHub Release의 설치 파일 게시가 필요합니다.
- ZIP 실행본은 같은 폴더에 적용하고 포터블 상태를 유지합니다. 설치판은 기존 Windows 제거 항목을 갱신합니다. 설치 경로 쓰기 권한이 필요합니다.
- 설정과 활동 기록은 유지합니다. 프로토콜, 수집량, 업로드 권한, 서버와 DB 변경은 없습니다.
- 게임 부하 중 출력 FPS, 세션 종료 경계, cadence 품질과 용량 gate 재측정은 기존 후속 과제로 남아 있습니다.
- 개발 후보의 검증 결과 및 실게임 미실행 범위는 `docs/UPDATE_0.4.1_2026-09-08_KO.md`를 참조합니다.
