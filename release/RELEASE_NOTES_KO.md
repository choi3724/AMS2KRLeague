# AMS2 리그 오버레이 0.5.1

- 텔레메트리·속도계·기어를 각각 독립된 오버레이로 추가했습니다. 각 패널의 위치와 크기를 따로 조절하고 표시 여부를 선택할 수 있습니다.
- 텔레메트리 그래프가 오른쪽에서 시작해 왼쪽으로 흐르며 부드러운 곡선으로 표시됩니다. 제목의 '최근 10초' 문구를 제거했습니다.
- 우측 입력 막대를 A(악셀)·B(브레이크)·C(클러치)·H(핸드브레이크) 순서로 표시합니다. 기본 색상은 녹색·빨간색·파란색·보라색이며 프로그램에서 변경할 수 있습니다.
- 속도는 'xxx km/h', 기어는 네모 테두리 안에 '기어'와 숫자로 표시합니다. 속도계와 기어의 글꼴을 각각 변경하고 저장할 수 있습니다.
- AMS2 한글패치와 같은 Pretendard Medium 글꼴을 기본 적용하고, 지정한 이미지를 설치 파일과 실행 프로그램의 아이콘으로 적용했습니다.
- 위치·크기 편집 중 가상 주행 그래프와 숫자를 표시해 패널 조절을 돕습니다.
- 게임을 종료하지 않고 오버레이를 자동 업데이트하며, 업데이트 후 프로그램을 재실행하고 상태창을 표시합니다.
- 연습·예선·레이스 기록을 모아 전체 레이스가 종료된 뒤 한꺼번에 전송합니다.
- 늦게 참가한 사용자도 실제 참가 시점부터 기록하고, 다른 참가자와 같은 레이스 종료 기준으로 기록을 마감합니다.
- 결과 화면에서 같은 경기 기록이 반복 생성되는 문제와 예선 종료 상태를 레이스 종료로 잘못 처리하는 문제를 방지합니다.
- 세이프티카가 남아 있어도 참가자의 레이스 종료와 기록 범위를 올바르게 판정합니다.
- 완주·리타이어·미완주·실격 후 차량이 비활성 상태가 되더라도 확인된 결과와 랩 기록을 보존합니다.
