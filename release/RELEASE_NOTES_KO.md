# AMS2 리그 오버레이 0.9.3

## 기능 추가
- 게임 없이 UI를 편집할 때 각 오버레이를 우클릭하면 해당 설정 페이지를 열 수 있습니다. 글꼴, 글자 크기, 디자인과 관련 색상을 바꾸는 즉시 미리볼 수 있습니다.
- 오버레이를 한 단계씩 앞뒤로 이동하거나 맨 앞·맨 뒤로 배치할 수 있습니다. N 계기판도 겹침 순서를 조절할 수 있으며 저장한 순서는 다시 실행해도 유지됩니다.

## 버그 수정
- 설정을 취소하면 미리보기 중 바꾼 모양과 겹침 순서가 원래대로 돌아가도록 수정했습니다.
- 오버레이를 이동하거나 크기를 바꾼 뒤 겹침 순서가 다시 바뀌는 문제를 수정했습니다.

# AMS2 리그 오버레이 0.9.2 업데이트

- 업데이트 확인·다운로드·설치·자동 재실행이 실패하면 해당 사용자의 바탕화면에 시각별 진단 로그를 남깁니다. 로그를 쓰지 못해도 기존 버전과 내부 로그는 유지합니다.
- 같은 설치 폴더의 오버레이가 중복 실행되어 자동 업데이트를 막는 문제를 예방합니다. 설치를 연기한 경우 차단 프로세스의 PID와 확인 가능한 경로를 기록합니다.
- 글자가 표시되는 12개 오버레이마다 글꼴과 창 크기와 독립적인 내부 글자 크기를 설정할 수 있습니다. 일반형·확장형 N 계기판은 사용자 요청에 따라 제외했습니다.
- 확장 N 계기판의 토크를 부호를 유지하며 정수로 반올림하고, 실제 기록에서 관측된 터보 압력 범위도 표시합니다. 터보 압력의 bar 환산은 원본 게임 계기판과 아직 대조하지 못했습니다.
- Windows 빌드·자동 테스트·패키지 검증을 수행했습니다. 사용자 PC의 자동 업데이트 성공, 실제 AMS2 주행·VR·물리 트리플 모니터, 성능 개선은 검증 전입니다. Monitor 성능 상태는 RED입니다.

# AMS2 리그 오버레이 0.9.1 업데이트

- 레이스 순위 타워는 각 차량이 현재 코스 지점을 통과한 시각과 1위의 같은 지점 통과 시각 차이를 표시합니다. 관측 이력이 부족하면 `—`, 한 바퀴 이상 뒤처지면 랩 차이를 표시합니다. 연습·예선은 기존 최고 랩 표시를 유지합니다.
- 확장 N 계기판은 터보 압력, 일반 부스트량, ERS 운용 모드를 구분해 표시합니다. 터보 수치는 요청에 따라 `bar`로 표기하지만 공유 메모리 명세에는 압력 단위가 없어 실제 차량 대조가 필요합니다. ERS 표시는 출력량이나 잔량이 아닌 운용 모드입니다.
- 토크는 소수 첫째 자리와 음수 부호를 보존합니다. 독립 기어 오버레이는 중립을 N, 후진을 R로 표시합니다.
- 레이스 컨트롤 글자 크기를 설정에서 75~200%로 따로 조절할 수 있습니다.
- Windows Release 빌드와 자동 테스트 및 WPF 캡처를 검증했습니다. 실제 AMS2 주행, 터보 단위, 실시간 1위 간격의 게임 기본 순위표 대조, VR·물리 트리플 모니터와 성능은 아직 검증하지 않았습니다. Monitor 성능 상태는 RED입니다.

# AMS2 리그 오버레이 0.9.0 업데이트

- 공개되지 않았던 0.8.4의 모니터 HUD CPU 렌더링, 게임 데이터 전용 읽기 스레드, 값이 바뀔 때만 다시 그리기, HUD 프레임 제한 설정을 포함했습니다.
- 레이싱 계기판 오른쪽 아래의 `남은` 표기를 세션에 맞는 `남은 시간` 또는 `남은 랩`으로 바꿨습니다.
- 레이스 컨트롤 카드의 글자가 작은 카드나 세로 카드에서 상자를 벗어나지 않도록 크기와 배치를 조정했습니다.
- 속도계와 기어 글꼴을 선택할 때 저장 전에도 선택한 글꼴로 예시를 볼 수 있습니다.
- 레이스 순위 타워에는 각 차량의 최고 랩과 1위 차량의 최고 랩 차이를 표시합니다. 연습·예선 등은 기존 최고 랩 표시를 유지합니다. 이 차이는 실시간 차량 간 간격이 아닙니다.
- 실제 AMS2 주행·VR·물리 트리플 모니터에서 화면과 성능은 아직 검증하지 않았습니다. 모니터 끊김 개선 효과도 게임에서 확인이 필요합니다.

# AMS2 리그 오버레이 0.8.4 업데이트

- 게임 중 모든 HUD가 0.2~0.5초마다 뚝뚝 끊기던 문제를 줄이기 위해 HUD를 GPU 대신 CPU로 그리도록 바꿨습니다. 게임이 GPU를 모두 사용할 때 HUD가 GPU 순서를 기다리며 멈추는 구조를 피합니다.
- 게임 데이터 읽기를 전용 스레드로 옮기고, 계기판·페달 값 읽기가 게임의 데이터 갱신과 겹쳐도 같은 프레임에서 다시 읽도록 했습니다.
- 모든 HUD가 값이나 움직임이 바뀔 때만 다시 그리도록 했습니다. 게임이 새 데이터를 주지 않았거나 순위표 내용이 같으면 다시 그리지 않습니다.
- N 계기판 창은 시작 연출 중에만 불꽃 영역까지 크게 쓰고, 평소에는 계기판 크기로 줄여 그리는 양을 줄였습니다. 저장한 위치와 크기는 그대로입니다.
- 색상·글꼴·핸들 설정에 "HUD 프레임 제한"을 추가했습니다. HUD를 1초에 최대 몇 번 그릴지 30~240 FPS 사이에서 1 FPS 단위로 정할 수 있고 기본은 60 FPS입니다. 높을수록 부드럽지만 그만큼 CPU를 더 사용합니다.
- 문제가 생기면 AMS2LeagueClient.exe를 --monitor-hardware 인자로 실행하면 0.8.3의 GPU 표시 방식으로 돌아갑니다.
- 기록 수집·전송 방식은 바뀌지 않았습니다.
- 실제 게임에서의 효과는 아직 검증 전입니다. Monitor 성능 상태는 RED입니다.

# AMS2 리그 오버레이 0.8.3 업데이트

- 간결 N 계기판의 상단 테두리가 원형을 따라 끝까지 이어지도록 수정했습니다.

- 기본 WPF와 명시적 시험용 --monitor-retained-n 경로를 함께 수정했습니다. 기존 수집·기록·전송 계약은 유지합니다.
- 실제 게임·VR·물리 트리플 모니터의 화면 및 성능은 검증 전입니다. Monitor 성능 상태는 RED입니다.
