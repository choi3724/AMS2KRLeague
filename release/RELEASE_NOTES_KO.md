# AMS2 리그 오버레이 0.4.5
## 변경
- 텔레메트리·속도계·기어를 각각 이동/크기 조절 가능한 독립 패널로 추가.
- 텔레메트리 그래프는 오른쪽에서 왼쪽으로 흐르고, 표시 선에 100ms 평활화와 곡선 연결 적용. 제목은 '텔레메트리'. 우측 막대는 A(악셀)·B(브레이크)·C(클러치)·H(핸드브레이크). 막대/입력값과 저장 원본은 보정하지 않음.
- 네 입력 색상 및 속도계/기어 글꼴 설정과 저장. 한글패치 0.7의 Pretendard Medium을 기본 폰트로 내장.
- 사용자 지정 설치·실행 아이콘. 업데이트 후 상태창 자동 재실행, 실행 직후 종료 실패 기록.
- 같은 캡처의 연습·예선·레이스는 로컬에 모으고, 레이스 전체 결과가 안정된 종료 상태이며 최종 저장이 끝난 뒤 일괄 업로드.
- 늦은 참가자는 실제 관측 시작을 유지하고 같은 전체 레이스 종료 판정을 사용. 결과 화면의 반복 스냅샷으로 새 기록을 만들지 않음.
- 세이프티카 원본을 유지하면서 위치 0·주행 상태가 드라이버의 종료 판정을 막지 않도록 보완.
- 예선 완료 상태가 레이스로 잠시 복사되는 구간과 트랙 정보가 비워진 구간의 잘못된 수집 방지.

## 전송 및 검증 범위
- 기존 서버 계약에 맞는 여러 Compact 청크를 종료 후 대기열에서 순서대로 전송합니다. 하나의 거대 요청이나 서버 원자적 일괄 수신으로 바꾸지 않습니다.
- 기존 싱글/미확인 전송 보류, 재시도, 중복 방지, 비공개 스트림 권한 검사는 유지합니다.
- 전체 종료가 관측되지 않았거나 종료 저장 증거가 없는 기록은 로컬에 보관합니다. 관측하지 못한 초반 구간을 채우거나 결과를 완전한 기록으로 바꾸지 않습니다.
- 웹사이트의 과거 종료 무결성·사고 조회 경고 수정은 별도 분석 대상으로 보류합니다.
- Release 경고/오류 0, Client 117/117·Activity 104/104, WPF 화면·프레임 검증, 배포 자료 감사 및 격리 설치 검증을 통과했습니다. 실게임 멀티플레이 및 운영 서버 데이터 변경은 실행하지 않았습니다.
