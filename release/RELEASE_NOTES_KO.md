# AMS2 리그 오버레이 0.7.3 업데이트

### N 계기판 자동 최대 눈금 수정

- 레드존 시작 위로 최소1,000RPM 여유를 확보한 뒤 천 단위로 올림합니다.
- 레드존6,800RPM이면 최대8,000RPM,14,800RPM이면 최대16,000RPM까지 표시합니다. 정확히7,000RPM이면 최대8,000RPM입니다.
- 일반형·확장형과 설정창에 같은 계산을 적용하며, 숫자·눈금·바늘·색상 배경을 함께 정렬합니다.

- 수집·기록·전송 원본과 폰트·이미지·기존 렌더링 구조는 변경하지 않았습니다.
