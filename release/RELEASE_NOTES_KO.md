# AMS2 리그 오버레이 0.6.0 업데이트

### VR 표시 추가
- 모니터 / VR / 동시 표시를 선택할 수 있습니다.
- VR 화면의 위치·크기·거리·각도를 조절할 수 있습니다.
- 고개를 따라 움직이거나 한 자리에 고정하도록 설정할 수 있습니다.
- SteamVR 환경에서 시험 지원합니다.

### 게임 없이 레이아웃 편집
- 게임을 켜지 않고도 주행 화면과 대기 화면을 따로 편집할 수 있습니다.
- 미리보기 데이터를 보면서 각 UI의 위치와 크기를 조절할 수 있습니다.

### 기록 전송 개선
- 압축을 지원하는 서버에 기록을 보낼 때 업로드 용량을 줄였습니다.
