# AMS2 League Overlay 0.3.1 — 레이아웃 / 모션 / 개별 랩 타이밍 Hotfix

GitHub Latest로 게시합니다. `v0.3.0`과 안정 기준선 `v0.2.2`는 수정하지 않습니다.

## 변경 사항

- 순위 타워 마지막 행 잘림 수정. 창을 세로로 늘리면 더 많은 참가자가 즉시 표시됩니다(2~64행). 상위 순위 우선, 범위 밖 플레이어 마지막 고정을 유지합니다.
- 편집 미리보기와 실제 적용의 행 수를 일치시켰습니다. 내용을 가리던 편집 상단 바를 없애고 테두리 안 드래그 / 오른쪽 아래 손잡이를 사용합니다.
- 보조 카드의 가로·세로 크기를 독립적으로 적용합니다. Race Control은 글자를 늘여 찌그러뜨리는 대신 창 크기에 맞춰 줄바꿈·배치·글자 크기를 조절합니다. 낮은 창에서는 보조 이력보다 현재 알림을 우선합니다.
- 시간 갱신 때 행 컨테이너를 교체하거나 레이아웃을 강제 갱신하지 않습니다. 필요한 속성만 갱신하고, 데이터 투영보다 WPF 모션 렌더링이 우선하도록 조정했습니다.
- 동일 황색기의 snapshot/history 갱신과 확장→축약 전환에서 등장 애니메이션을 반복하지 않습니다. 실제 새 메시지와 상태 전환 효과는 유지합니다.
- 모든 참가자에게 같은 섹터 합계가 표시되던 경로를 제거하고 각 차량의 라인 통과에 기초한 개별 랩 시계를 추가했습니다.

## 타워 시간 읽는 방법

| 표시 | 의미 |
|---|---|
| `0:12.345` | 로컬 플레이어의 AMS2 직접 현재 시간 |
| `~0:12.345` | 해당 차량의 라인 통과를 관측한 뒤 측정한 UI용 현재 랩 시간(공식 기록 아님) |
| `L1:40.123` | 현재 랩 시작을 관측하지 못했을 때 AMS2가 제공한 직전 랩 |
| `--` | 신뢰 가능한 시간 없음 |
| `FIN` / `RET` / `DNF` / `DSQ` | 참가자별 종료 상태 |

Practice/Qualifying 완료 시에는 AMS2의 유효 Best Lap을 표시합니다. 중간 접속 후 첫 라인 통과 전에는 시간을 만들어내지 않습니다. 관측 시계는 약 20Hz UI 관측에 따른 오차가 있으며, 결과나 Compact 원본으로 저장/전송하지 않습니다. 선두 완주나 시간제 세션의 남은 시간 0이 후속 차량의 시계를 정지시키지 않습니다.

## 검증

- Release build: 경고 0 / 오류 0
- Client/UI/SHM/Transport: 77/77 PASS
- Activity/Archive/Compact: 97/97 PASS
- Race Control 14개 크기/상태 조합의 텍스트 bounds, 타워 리사이즈/저장/미리보기, waiting/순위 변화/Best Lap/개별 종료 회귀 검증
- 실제 WPF 순위 행 재정렬 + 20Hz 데이터 갱신 프로브: 약 140회/초 좌표 갱신, Rendering 간격 p95 9.42ms. **게임 FPS 측정이 아니며 게임 부하에서의 화면 출력 120 FPS 보장은 아닙니다.**

## 유지되는 범위와 제한

- Cafe24 배포, Compact Protocol, capture schema, 업로드 구조, 서버 API/DB는 변경하지 않았습니다.
- 0.3.0의 Compact world cadence 500ms를 유지합니다. 기존 업로드량/완전성/Private Driver authority 제한도 유지됩니다.
- 원본 게임 HUD와 같은 위치에 놓으면 투명 오버레이 뒤로 기본 HUD가 비칠 수 있습니다. 게임 HUD 설정을 자동 변경하지 않습니다.
- 극단적으로 작은 창에서는 모든 핵심 문구를 담기 위해 글자가 작아집니다. 다른 보조 카드는 가로·세로 독립 배율에 따라 글자 비율도 변할 수 있습니다.
- 30fps 휴대폰 영상만으로 120/144Hz 출력 품질을 확정할 수 없습니다. 실게임 부하의 체감 끊김 해소는 별도 확인이 필요합니다.
- 코드 서명 인증서가 없어 SmartScreen 경고가 표시될 수 있습니다.
