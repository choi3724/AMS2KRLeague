# AMS2 리그 오버레이 0.4.4 — 배치 편집 미리보기

## 변경
- 위치·크기 편집 중 이벤트가 비어 있으면 예시 기록을 표시합니다. 레이스 컨트롤에도 미리보기를 표시합니다.
- 패널 테두리뿐 아니라 내부 전체에서 마우스로 선택·이동할 수 있습니다. 오른쪽 아래 크기 조절 손잡이를 유지합니다.
- 실제 이벤트가 들어오면 실제 내용을 표시하며 편집 종료 시 실제 상태와 클릭 통과를 즉시 복원합니다.
- 가상 내용은 편집 화면 전용이며 실제 기록·업로드·저장된 레이아웃에 포함되지 않습니다.
- 0.4.3의 타워 자동 높이·최고속 랩 표시·게임 실행 중 업데이트를 포함합니다.

## 설치와 검증
- AMS2-League-Overlay-0.4.4-Setup.exe 또는 AMS2-League-Overlay-0.4.4-win-x64.zip.
- 0.4.3은 게임 종료 없이 자동 업데이트할 수 있습니다. 업데이트 중 오버레이 표시·수집에는 짧은 공백이 있습니다.
- 0.4.1~0.4.2의 첫 자동 업데이트는 기존 코드의 게임 종료 대기를 따릅니다. 0.4.0 이하는 수동 설치가 필요합니다.
- WPF 이벤트 소멸 뒤 편집·반복 갱신·실제 이벤트·저장/취소 복원, 패널 9지점의 입력 면·커서·크기 조절 검증을 통과했습니다. Release 경고/오류 0, Client 113/113, Activity 102/102.
- 게임 조작 및 운영 서버/DB 변경은 없습니다. 기존 자동 모드의 로그 부족·세션 경계 보류와 수신 서버 검증 제한은 유지됩니다.
