# AMS2 리그 오버레이 0.4.2 — 싱글·멀티 자동 구분

## 변경
- 수동 모드 선택을 제거하고 AMS2 공식 접속 로그의 로컬 접속·방 생성·퇴장으로 자동 판정합니다. 상태창과 대기 오버레이에 반영합니다.
- 싱글플레이와 모드 미확인 기록은 로컬에 보관합니다. 결과·Witness·리플레이 모두 확인된 멀티 구간만 업로드하며, 기존 대기열에도 적용합니다.
- 결과와 Witness의 raceMode는 MULTIPLAYER / SINGLE_PLAYER / UNKNOWN입니다. 리플레이 사이드카 raceMode와 HTTP X-AMS2-Race-Mode에도 같은 구분값을 전달합니다.
- 모드 미확인 항목이 멀티 기록의 업로드 순서를 막지 않습니다. Compact/GZIP 원본, 해시, 세션 식별자와 기존 저장 데이터는 유지합니다.
- 0.4.1의 한글 안내, 완주 표시, 페널티 열, GitHub 자동 업데이트를 포함합니다.

## 설치
- AMS2-League-Overlay-0.4.2-Setup.exe 또는 AMS2-League-Overlay-0.4.2-win-x64.zip.
- 0.4.1은 자동 업데이트 대상입니다. 게임 실행 중에는 설치를 미루며 종료 후 적용합니다.
- 0.4.0 이하는 0.4.2를 한 번 수동 설치해야 합니다.

## 검증과 제한
- Release 빌드 경고·오류 0, Client 111/111 및 Activity 102/102 통과. 실제 보관 로그 6/6에서 접속·퇴장 구간 파싱 확인.
- 로그 부재·형식 불일치·15초 이상 멀티 로그 미갱신 시 현재 모드는 미확인입니다. 업로드는 실제 로그가 확인한 시각까지만 허용합니다. 로그가 조용한 멀티 방이나 퇴장 경계에 걸친 기록은 보류될 수 있습니다.
- 실게임 모드 전환 및 운영 서버의 새 리플레이 헤더 저장·표시는 미검증입니다. 서버 수신 측은 X-AMS2-Race-Mode를 raceMode에 매핑해야 합니다. 서버/DB 변경은 포함하지 않습니다.
