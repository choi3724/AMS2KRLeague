# AMS2 리그 오버레이 0.7.0 업데이트

### 오버레이 선택 화면
- 각 오버레이의 미리보기를 보면서 필요한 항목을 선택할 수 있습니다.
- 순위 타워와 텔레메트리는 **기본 / 개량** 디자인을 선택할 수 있습니다.
- 오버레이 목록을 두 칸씩 배치해 한눈에 더 많은 항목을 볼 수 있도록 바꿨습니다.

### 주행 화면
- 속도·기어·RPM을 함께 보여주는 레이싱 계기판을 추가했습니다.
- 텔레메트리 그래프와 페달 게이지를 분리했습니다. 위치와 크기를 각각 조절할 수 있습니다.
- 핸들 회전과 각도 표시를 다듬고, ABS가 작동하는 구간은 브레이크 그래프에 노란색으로 표시합니다.
- 텔레메트리 제목을 제거하고 그래프 선을 굵게 조정했습니다.
- 뒤차와의 접전 알림을 추가했습니다.
- 운전 정보 갱신과 그래프·계기판 애니메이션을 더 부드럽게 개선했습니다.

- VR 화면 갱신 방식을 개선했습니다.

### 기록 저장
- 노르트슐라이페처럼 20km가 넘는 서킷에서 거리 상한 때문에 기록 저장이 멈추던 문제를 수정했습니다.
- 서버 업데이트를 기다리는 장거리 기록은 보관했다가 자동으로 다시 전송합니다.
