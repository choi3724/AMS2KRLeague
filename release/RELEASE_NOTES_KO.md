# AMS2 리그 오버레이 0.7.2 업데이트

### N 계기판

- N 계기판 일반형과 확장형을 추가하고, 차량에 맞춰 RPM 숫자·눈금·바늘·색상 배경이 함께 바뀌도록 했습니다.
- 기본 경고는 엔진 최대 RPM의90%부터 노랑,97%부터 빨강으로 표시합니다. 이는 오버레이 표시 정책이며 게임이 직접 제공한 경고 경계값은 아닙니다.
- 빨강 시작보다 큰 다음1000 RPM 단위를 자동 최대 눈금으로 사용합니다. 레드존에 도달하면 외곽5쌍이 완등하고 빨간 영역이200ms 주기로 점멸합니다.
- 저장된 차량별 수동 보정은 우선 적용합니다. 직접 지정을 해제하면 새 공통 정책으로 돌아갑니다.
- 차량 전환 시 이전 RPM 기준을 제거하고, 같은 차량의 일시적인 무효값에는 마지막 유효 기준을 유지합니다.
- 눈금 중복, 속도 숫자·단위 정렬, 숫자 통과 확대와 경고 효과를 조정했습니다.

### 화면 갱신과 업데이트 안내

- Monitor 표시 시계를 공유하고, 변경된 표시만 갱신하며 그래프·문자·geometry 자원을 재사용하도록 개선했습니다.
- 숨김·OFF 전환과 마지막 구독 해제 때 불필요한 갱신과 자원 유지가 남지 않도록 보완했습니다.
- 업데이트 상태 안내를 첫 화면에서 확인할 수 있도록 하고 설치·재실행 안내를 보완했습니다.
- 기록·전송 원본과 계약은 유지합니다. 직접 GPU graph 시험 코드는 제품에 적용하지 않았습니다.

### 검증 범위와 알려진 제한

- 로컬 코드·계약 회귀와 실제 WPF 렌더 검사를 수행했습니다. 자세한 결과는 저장소의0.7.2 릴리즈 보고서를 참고하세요.
- 실게임에서 보인 끊김이 해결됐다고 판정하지 않았습니다. **기존 Monitor 성능 RED를 유지하며60fps 완료를 주장하지 않습니다.**
- 이번 버전의 동일 조건 실게임 성능 비교·장시간 수집·실제 서버 전송·VR 실기기 검증은 NOT TESTED입니다. 하네스 결과를 실제 화면 FPS로 해석하지 마세요.
