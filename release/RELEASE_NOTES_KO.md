# AMS2 리그 오버레이 0.7.5 업데이트

### 수정사항

- 트리플 모니터에서 편집·저장한 UI가 게임 진입 후 과도하게 확대되는 문제 수정
- HUD별 저장 크기를 유지하고, 일부 HUD만 다시 편집해도 다른 HUD의 크기가 바뀌지 않도록 수정
- 기존 배치 설정을 처음 변경 저장할 때 원본 백업 보존

### 검증 범위와 알려진 제한

- 자동 회귀와 실제 WPF 창에서 저장·복원, 순위표 인원 변화 시 크기 유지 검증
- 물리 트리플·혼합 DPI·실게임·VR 실기기 검증은 NOT TESTED
- 프레임 끊김 해결 업데이트는 아니며 기존 Monitor 성능 RED 유지
- 기존 N 계기판 디자인·RPM 정책과 수집·기록·전송 동작 유지
