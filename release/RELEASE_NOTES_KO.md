# AMS2 리그 오버레이 0.7.7 업데이트

### 수정사항

- 관전 중인 참가자의 드라이브스루·스톱앤고 페널티가 순위표에 표시되도록 수정 (두 순위표 디자인 공통)
- N 계기판의 RPM 눈금을 미리 만든 이미지로 표시하고, 속도·수치 문자와 연료·상태 표시를 같은 값일 때 다시 만들지 않도록 개선
- 주행 그래프가 화면에 보일 때만 그래프용 주행 이력을 보관하도록 변경 (리그 기록 수집·전송은 변경 없음)

### 시험 기능 (기본 꺼짐)

- 실행 인자 `--monitor-glass`: HUD를 DWM 합성 창으로 표시하는 시험 경로
- 실행 인자 `--monitor-retained-n`: N 계기판을 DirectComposition으로 그리는 시험 경로 (`--monitor-glass` 포함)
- 인자 없이 실행하면 기존 표시 경로 그대로 동작하며, 시험 경로는 메모리 사용이 늘어날 수 있음

### 검증 범위와 알려진 제한

- 자동 회귀 테스트와 Release 빌드 경고·오류 0 확인
- 실게임·VR 실기기·물리 트리플·혼합 DPI 검증은 NOT TESTED
- 프레임 끊김 해결 업데이트는 아니며 기존 Monitor 성능 RED 유지
- N 계기판 디자인·RPM 정책과 수집·기록·전송 동작 유지
