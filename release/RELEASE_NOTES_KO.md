# AMS2 리그 오버레이 0.7.6 업데이트

### 수정사항

- 트리플 모니터에서 편집·저장한 UI의 위치 간격이 게임 진입 후 확대되는 문제 수정
- 0.7.5에서 크기만 유지되고 가로 위치가 이동하던 문제를 수정하여 저장한 위치와 크기를 함께 유지
- 기존 배치 설정을 초기화하지 않고 복원하며, 게임 창 이동 시 오버레이 추종 동작 유지

### 검증 범위와 알려진 제한

- 제공된 배치 설정과 실제 WPF 창에서 위치·크기·재편집·저장·복원 검증
- 물리 트리플·혼합 DPI·실게임·VR 실기기 검증은 NOT TESTED
- 프레임 끊김 해결 업데이트는 아니며 기존 Monitor 성능 RED 유지
- N 계기판 디자인·RPM 정책과 수집·기록·전송 동작 유지
