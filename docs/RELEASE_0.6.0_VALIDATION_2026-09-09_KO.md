## 검증 범위와 후속 작업

실제 VR 헤드셋과 SteamVR 게임 화면은 검증하지 않았다. 사용자에게 기기가 없으므로 VR은 시험 지원으로 표시했다. 모의 런타임과 WPF 화면 검사, 공식 SDK 파일 해시·DLL 로드 검사를 통과한 상태다. 실제 기기 점검은 VR_TEST_CHECKLIST_2026-09-09_KO.txt를 사용한다.

실제 운영 서버의 gzip 수신·해시 검증은 서버 담당의 배포 후 연동 검증이 남아 있다. 서버가 지원을 알리지 않으면 일반 JSON 전송을 유지한다. 서버 코드와 운영 데이터는 변경하지 않았다.

게임 파일·게임 프로세스·VR 런타임 설정은 변경하지 않았다. OpenVR 라이브러리는 오버레이 앱만 로드하며 배포에 공식 라이선스를 포함한다.

기존 gzip·레이아웃·VR 문서의 미커밋/시험 빌드 표기는 각 기능 구현 당시의 기록이다. 이번 릴리스에서 해당 구현을 0.6.0으로 묶었다. 기존 RESULT_TERMINAL_SAFETY_FIX 문서는 이미 0.5.1에 포함된 별도 작업의 인수인계 기록으로 보존했으며, 해당 기능을 0.6.0 변경 공지에 다시 넣지 않았다.
