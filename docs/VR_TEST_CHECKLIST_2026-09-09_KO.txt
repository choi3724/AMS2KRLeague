AMS2 리그 오버레이 0.6.0 · VR 사용 및 점검표
0.6.0에 포함된 SteamVR 시험 기능의 사용 안내입니다.
실제 헤드셋에서의 표시와 성능은 검증 전입니다.

실행
1. 기존 오버레이 프로그램을 종료합니다.
2. 압축파일을 폴더에 모두 풉니다. 실행파일만 따로 옮기지 마세요.
3. AMS2LeagueClient.exe를 실행합니다.
4. 상태창의 [모니터·VR 표시 설정]을 엽니다.
5. [모니터 표시 / VR 표시 / 모니터 + VR 동시 표시] 중 선택하고 [적용]을 누릅니다.
   기본값은 모니터 표시입니다.

VR 사용
- 현재 구현한 경로는 SteamVR입니다. 헤드셋을 연결하고 SteamVR을 실행한 뒤
  SteamVR을 통해 AMS2를 실행하세요. 프로그램이 SteamVR을 대신 실행하거나 설정을 바꾸지 않습니다.
- Meta/Oculus 직접 실행, OpenComposite를 통한 OpenXR 단독 실행 등은 현재 지원하지 않습니다.
- VR 연결 상태와 오류는 상태창에 표시합니다. 연결 실패 시 5초 간격으로 재시도합니다.
- 실제 헤드셋 표시와 게임 성능은 검증 전인 시험 기능입니다.
- 폭·거리·좌우·상하·각도를 설정할 수 있습니다.
- [고개를 따라 움직이기]를 끄면 공간에 고정됩니다. [정면 재설정]으로 기준을 다시 잡습니다.
- 위치 설정은 PC의 프로그램 창에서 조작합니다. VR 컨트롤러 조작은 포함하지 않습니다.
- 기존 패널 배치를 하나의 투명한 VR 화면으로 표시합니다. 패널별 독립적인 3D 깊이는 지원하지 않습니다.
- 패널별 배치는 [게임 없이 주행 UI 편집 / 게임 없이 대기 UI 편집]에서 수정합니다.
  VR이 연결되어 있으면 이 미리보기도 헤드셋으로 전송합니다.
- 게임 데이터가 유효하지 않거나 다른 VR 앱으로 전환되면 실제 경기 HUD를 숨깁니다.
- VR 기능을 꺼도 데이터 기록·서버 전송 정책은 바뀌지 않습니다.

테스트할 내용
1. 헤드셋 기종, 연결 방법, SteamVR 버전, AMS2 VR 실행 방법을 기록합니다.
2. 먼저 동시 표시로 설정해 모니터·VR 양쪽에 같은 내용이 나오는지 확인합니다.
3. VR 전용에서 모니터 HUD가 숨겨지고 VR에는 남는지 확인합니다.
4. 글자·빨강/녹색/파랑·투명 배경·화면 방향·겹침을 확인합니다.
5. 거리·위치·크기·각도와 고개 추종/공간 고정/정면 재설정을 확인합니다.
6. 게임을 모니터 뒤로 보내거나 최소화해도 VR 장면이 AMS2인 동안 유지되는지 확인합니다.
7. SteamVR 종료·헤드셋 분리 후 프로그램이 계속 동작하며 재연결되는지 확인합니다.
8. 프로그램을 재실행해 표시 모드와 VR 위치 설정이 유지되는지 확인합니다.
9. VR 기능 켜기 전후 프레임 저하·끊김 여부를 확인합니다.
10. 다른 VR 게임/앱으로 전환했을 때 AMS2 HUD가 남지 않는지 확인합니다.

문제 제보
- 상태창의 VR 문구, 발생 시점, 위 테스트 중 실패한 번호를 알려주세요.
- 로그의 VR_STATUS 항목에 연결·오류 상태를 남깁니다.
- 로그 위치는 기본적으로 %LOCALAPPDATA%\AMS2KRLeague\logs 입니다.
- 설정: %LOCALAPPDATA%\AMS2KRLeague\overlay-layout.json
- 전체 사용자 데이터나 계정 토큰 파일을 공유하지 마세요.

이 빌드에는 기존 gzip 업로드 및 게임 없는 레이아웃 편집 변경도 포함됩니다.
gzip은 서버가 해당 업로드 경로의 지원을 알린 경우에만 사용합니다.
