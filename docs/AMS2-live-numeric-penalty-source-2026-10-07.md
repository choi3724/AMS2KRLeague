## 실시간 표시를 위한 검증 순서

1. 같은 PC에서 실제 일반 로비 경기의 시간 페널티와 순위 반환 페널티를 각각 한 번 재현한다. 게임 내 순위표가 보이는 순간의 짧은 화면 녹화와 동시간대 공유 메모리/UDP/`online.log` 타임스탬프를 대조한다. 캡처 프로그램은 게임 프로세스에 쓰거나 운영 업로드 대기열을 건드리지 않는다.
2. 공개 데이터에 해당 수치가 없다는 것을 재확인하면 **선택형 화면 판독**을 시제품으로 만든다. 게임 창의 순위표 영역만 낮은 빈도로 캡처하고, `+N sec`·`+N grid place` 및 해당 행의 참가자 이름/순위를 함께 인식한다. 이름과 현재 참가자 목록이 유일하게 맞을 때만 표시한다. 읽기 실패·순위표 숨김·화면 전환·중복 이름은 `—`로 둔다.
3. 화면 판독은 해상도, HUD 배치, 언어, VR, 독점 전체화면, 화면 효과에 따라 실패할 수 있다. 두 종류의 실제 발생 화면으로 오인식·지연·CPU/GPU 비용을 측정한 뒤에만 기본 기능으로 검토한다. 오버레이 자체가 캡처 영역에 들어가 재인식되지 않도록 게임 창 영역과 좌표를 검증한다.
4. Reiza가 향후 공유 메모리/UDP에 확정 수치 필드를 추가하면 화면 판독 대신 그 필드를 우선 사용한다. 전용 서버 이벤트는 별도 호환 기능으로만 고려한다.

현재 오버레이의 별도 수치 페널티 칸은 정확한 입력이 있을 때 값을 표시할 준비가 되어 있다. 게임 없는 편집 미리보기에는 `+33초`, `순위 +1`, `드라이브스루` 예시를 넣었으며 실제 경기 값으로 오해되지 않게 데모 경로에서만 생성한다.
