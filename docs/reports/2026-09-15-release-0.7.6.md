# v0.7.6 — 저장 HUD 위치 간격 유지

## 기준선과 범위

사용자의0.7.6 커밋·릴리즈 승인에 따라 공개0.7.5/main `1875dd1e60e55570d64e23de5c0d66d9ac97867b`에서 독립 릴리즈 체크아웃을 만들었다. 원본/기존 분석/후속 분석 트리와 설치본을 보존한다. 기존 GPU/DComp·성능 실험 변경은 포함하지 않는다.

기준선 Client162/162·Activity111/111, 빌드 warning/error0. 후보는 관련 회귀3개를 더한 Client165/165·Activity111/111이다.0.7.5 공개 자산/태그를 교체하지 않아 기존0.7.5 사용자는 새 버전 업데이트 대상으로 인식된다.

## REQ-RELEASE-076 수정과 증거

제공된 설정은 previewViewport와 HUD별 reference가2560×1440이고, 게임 화면은7680×1440이다.0.7.5는 크기만 reference로 복원하고 X/Y는 현재 게임 폭으로 환산해 가로 간격이3배 벌어졌다. 저장 설정과 두 화면의 위치 변화가 일치했고 실제 WPF에서도 같은 실패를 재현했다.

| HUD | 편집 X px | 0.7.5 게임 X px | 0.7.6 게임 X px |
| --- | --- | --- | --- |
| 순위표 | 590 | 1770 | 590 |
| 세션/랩 타임 | 915 | 2745 | 915 |
| 그래프 | 1220 | 3660 | 1220 |
| 페달 | 1188 | 3564 | 1188 |

제품 동작 변경은 `OverlayLayoutProfile.cs`의 X/Y 복원 기준2줄이다. 현재viewport 대신 저장reference를 곱해 픽셀 오프셋을 복원한다. 호출부의 게임 client 원점 합산은 유지하므로 게임 창 이동은 그대로 따라간다. 기존 크기 복원·음수좌표·화면 복구·설정 백업·schema1은 유지한다. reference와 PreviewViewport가 모두 없는 구형 설정은 기존 fallback을 유지하며, 제공된0.7.5 설정은 초기화 없이 복원된다.

회귀 변경은 `Program.cs`, `OverlaySizeTests.cs`, `HudEditedAspectTests.cs`, `TripleSuppliedLayoutTests.cs`, 테스트 프로젝트의 설정 fixture 포함이다. 과거 위치의 비례 확대 기대값을 저장 픽셀 오프셋 유지로 바꾸고 clamp/legacy 검증은 유지했다. 실설정 fixture에는 화면 배치와 디자인 설정만 있으며 수집 기록·인증정보를 포함하지 않는다.

폰트·이미지·N RPM·기본WPF·게임 데이터 수신/기록/전송 계약은 변경하지 않았다. 다른 제품 파일은 버전/문서 메타데이터만 변경했다.
