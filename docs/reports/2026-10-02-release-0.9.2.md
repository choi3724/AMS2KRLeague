# 0.9.2 Windows 릴리즈 검증 (2026-10-02)

## 기준선과 범위

작업 전 원격 `main`은 0.9.0 `3515967`, 작업 브랜치 `claude/jolly-hypatia-euwyty`와 `v0.9.1`은 `a7fcfa3`이었다. 따라서 기존 VS Code 그래프에서 `main`만 추적하면 0.9.1이 표시되지 않았다. 0.9.2에는 0.9.1 위의 미커밋 글꼴·내부 글자 크기 설정(12개 오버레이, N 계기판 제외), 토크 정수 반올림, 실제 기록 범위의 터보 표시, 동일 설치 경로 중복 실행 차단과 업데이트 진단 개선을 포함한다.

자동 업데이트의 준비·다운로드 실패와 설치 도우미의 설치·재실행 실패는 시각별 진단 로그를 해당 사용자의 바탕화면에 기록한다. 바탕화면을 쓸 수 없으면 기존 내부 로그·결과를 유지하며 오류를 추가로 일으키지 않는다. 설치 성공 때는 바탕화면 실패 로그를 만들지 않는다. 테스트는 임시 바탕화면 폴더를 사용한다. 실제 영향을 받은 사용자 PC의 업데이트 성공은 확인하지 못했다.
