## 안정화 변경

- `RetainedNPresenter.cs`: 측정용 환경변수 `AMS2_RETAINED_N_FREE_TICK` 분기를 제거하고 합성 주기 정렬 Commit만 남겼다. 5라운드 파일럿에서 정렬 방식의 3-vsync 이상 간격 비율이 자유 실행보다 낮았다(0.81/0.87/0.74% 대 1.06/1.18/0.96%).
- `App.xaml.cs`: 시작 로그 `MONITOR_PRESENTATION_PATH`의 연산자 우선순위 오류로 `retained-n-requested`가 glass 실패 시에만 기록되던 문제를 괄호로 수정했다.
- `OverlayWindowInterop.cs`: `WM_DWMCOMPOSITIONCHANGED` 처리에서 glass 재확장 실패가 메시지 hook 안에서 예외를 던지지 않도록 했다. 최초 구성 시 실패는 기존대로 예외로 알린다.
- Vortice.Windows와 SharpGen.Runtime(MIT) 고지를 `ThirdParty/Vortice/LICENSE.txt`로 추가해 배포 폴더에 복사한다. SharpGen.Runtime은 Vortice 3.8.3이 요구하는 2.4.2-beta다.
