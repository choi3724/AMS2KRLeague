# 자유 연습 표시·계기판 그림자 수정

2026-09-09 · 기준 0.6.0 (17d474e) · 로컬 수정본, 공개 릴리스 변경 없음

## 수정 내용

- 게임이 주행 중인데 남은 시간이 -1이고 경기 상태가 NotStarted라는 이유만으로 대기 화면을 선택하던 조건을 제거했다. 자유 연습·테스트·예선·포메이션 랩·레이스·타임어택에서 싱글/멀티/미확인 구분 없이 유효한 주행 HUD를 표시한다.
- 실제 게임 메뉴 상태에서는 대기 화면, 일시정지·리플레이·프런트엔드에서는 기존 숨김 정책을 유지한다.
- 남은 시간이 없고 종료 상태도 확인되지 않으면 숫자를 만들거나 종료로 추정하지 않고 —를 표시한다. 시간·랩 제한이 없는 주행의 0 / 0 랩 표시도 제거했다.
- 속도계 글자와 기어 제목·숫자에 검은색 그림자를 기본 적용했다. 텔레메트리·글꼴 설정에서 속도계/기어 그림자 색상을 각각 변경하고 기존 배치 설정 파일에 저장한다. 기존 설정 파일에 새 속성이 없으면 검은색을 사용한다.
- 싱글플레이 PC 기록과 확인된 멀티플레이만 서버에 전송하는 기존 정책을 유지한다. 수집·전송 런타임과 FutureTelemetry 파일은 기준 커밋과 변경 없음.
