# 전 패널 글꼴 비율 / 타이밍·무효 랩 표시 후속 수정 — 2026-09-06

## 상태

로컬 개발 수정본이며 제품 버전은 아직 0.3.1이다. commit/tag/Release 및 설치본 교체는 하지 않았다. 기존 v0.3.1 공개 자산, 실행 중인 게임과 오버레이는 변경하지 않았다. 이번 결과는 자동 테스트와 WPF fixture 렌더링 검증이며 실게임 화면 재검수나 120 FPS 실측 결과가 아니다.

## 변경 사항

| 요청 | 반영 내용 |
| --- | --- |
| 모든 패널에서 글자가 가로·세로로 찌그러짐 | 보조 패널 공통 경로의 비균등 `Stretch.Fill`을 제거했다. 패널의 가로·세로는 독립적으로 변경하되 논리 배치를 새 크기에 맞추고, 글자는 같은 X/Y 배율로 확대·축소한다. |
| 크기에 맞는 글꼴 크기 | 전후방 거리, 개인 타이밍, 세션 정보, 이벤트, 대기 화면은 기존 공통 Viewbox의 균등 배율을 사용한다. Race Control은 기존 반응형 글꼴 계산/균등 축소를 유지하고, 타워는 기존 폭 기준 글꼴 배율·높이 기준 행 수 계산을 유지한다. 별도의 수동 글꼴 크기 슬라이더를 추가한 것은 아니다. |
| 독립 크기에서 빈 공간/잘림 | 전후방 두 행은 남는 높이를 균등 배분하고, 개인 타이밍·이벤트·대기 내용은 세로 중앙에 정렬한다. 패널 외곽은 요청한 비율을 그대로 채운다. 좁은 축이 글꼴 크기의 상한이므로 넓히기만 했다고 글자가 가로로 늘어나지는 않는다. |
| Race 첫 랩에 플레이어만 타임 표시 | 타워에서 참가자별 `LapsCompleted == 0`이면 로컬/다른 참가자 모두 `--`로 표시한다. 각 참가자가 첫 랩을 완료하면 그 행부터 현재 타이밍을 표시한다. FIN/RET/DNF/DSQ는 그대로 표시한다. Practice/Qualifying와 별도 개인 타이밍 패널의 첫 랩은 숨기지 않는다. |
| 시간 앞의 `L` 의미 불명확 | `L`은 직전 랩 fallback 표시였다. 화면에는 숫자와 `직전` 상태로 구분한다. PIT/페널티 등 중요한 상태가 이미 있으면 그 상태를 유지하고 시간 앞에 `직전`을 표시한다. |
| 인정되지 않은 랩 타이머 | 게임의 lap-invalid 신호를 받은 참가자의 현재 랩 표시 시간을 고정하고 빨간 `무효`를 표시한다. 플레이어 개인 패널도 현재 랩 숫자를 고정한다. 다른 참가자, 원본 섹터 값 및 저장용 텔레메트리는 멈추지 않는다. |
| 무효 랩 이벤트가 잘 보이지 않음 | 기존 InvalidLap 이벤트를 우선 표시하고 4초 유지한다. 동일 랩 신호 반복으로 다시 알리지 않는다. Finish/RET/DSQ 알림은 무효 랩 카드보다 우선한다. |
| 그린 플래그 카드의 작은 글씨/히스토리 | UI 히스토리 목록과 개수 배지를 제거했다. 현재 제목/메시지는 기본 24로 확대하고 빈 보조 문구는 공간을 차지하지 않게 했다. |

앞서 수정한 AI 참가자별 현재 섹터 타이밍과 전후방 시간차(`s`) 표시는 보존했다. 첫 랩을 표시할 수 없어서 숨기는 것이 아니라, 후속 사용자 요청에 따른 Race 타워 표시 정책이다.

## 원인과 경계

### 글꼴 왜곡

타워 외 여러 패널이 같은 `AuxiliaryOverlayWindow`의 `Viewbox Stretch.Fill` 경로를 사용했다. 패널의 가로·세로를 따로 바꾸면 자식 글꼴에도 서로 다른 배율이 적용됐다. 공통 경로를 수정해 개별 패널마다 별도 크기 관리기를 만들지 않았다. 레이아웃 편집 미리보기와 저장 후 적용도 같은 경로를 사용한다.

### 무효 알림 지연

실행 로그 `client-20260906-101741.log`의 읽기 전용 확인 결과:

- 10:41:31.8227159: InvalidLap 감지, 기존 우선순위 Low.
- PodiumExit(Critical)와 RaceFastestLap 등의 이벤트가 앞서 표시됨.
- 10:41:35.9062352: InvalidLap 표시 시작. 약 4.084초 지연, 기존 유지 시간 2초.

따라서 해당 표본은 원본 신호 누락이 아니라 표시 큐 지연이었다. 수정은 기존 이벤트 엔진/큐를 재사용한다. 게임이 랩 무효를 알린 경우에만 `현재 랩 무효`를 표시한다. 단순 경고만 있거나 원인이 제공되지 않은 경우 임의로 `트랙 리미트`라고 단정하지 않는다.

### 무효 시간의 의미

고정 숫자는 무효 신호를 처음 받은 순간 관측한 UI 시간이며 공식 랩 기록이 아니다. 해당 랩의 유효 시간이 없고 직전 랩 fallback만 있으면 `-- / 무효`로 표시한다. 참가자 슬롯의 이름/차량/클래스, 랩 카운터, 표시 대상, 세션 상태 generation 변경 시 이전 고정값을 재사용하지 않는다. 정상/terminal 상태로 전환하면 고정을 해제한다. 개인 S1/S2/S3 숫자는 원본 값이며 이번 고정 대상은 현재 랩 타이머다.

### 히스토리와 서버

Race Control의 내부 history 및 기존 raw flag/event 캡처 경로는 유지했다. Compact Protocol, Capture Schema, 업로드 구조, Server API/DB에는 변경이 없다. UI에 있던 히스토리 문장 자체를 새로 서버에 보내는 작업은 하지 않았다. 기존 raw flag 기록과 별도로 GREEN 전용 story 이벤트가 항상 존재한다고 보장하지 않는다. 이번 턴에는 서버 수신을 재검증하지 않았다.
