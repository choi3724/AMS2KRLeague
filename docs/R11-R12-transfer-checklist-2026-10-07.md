# R11·R12 퀄리파잉 전송 전 확인표 — 2026-10-07

R11 예선→레이스 전환 간격은 300.0478ms, R12는 300.0526ms였다. 이벤트 지문은 R11 `38a5053267a5f5c2c5b3d8b939f5d3fc5f0f8f11bee7d6ac1055f1035a7aa393`, R12 `ca847c5042c14f21010cd3570e9549808c1640939c35ae1c92ff9078d6bd446d`로 각각 예선·레이스가 일치한다. 각 경기 안에서 소스 클라이언트·서킷·레이아웃·차량 클래스도 일치하고 세션 지문과 캡처 ID는 바뀌었다. 안전차를 제외한 이름+차량+클래스 일치는 R11 예선 16명 중 레이스 witness 15명, R12 예선 12명 중 레이스 witness 10명이다. 이 대조는 **경기 연결 후보**의 근거이며 운영 DB의 기존 payload 해시 중복 검사를 대신하지 않는다.

복사본 게이트 실행 결과 구버전 대기열의 예선 6행·17행·13행 모두 자동 전송 대상이 아니었고 `GetDueBatch=0`이었다. 메모리에서만 대상별 새 정책 적용을 가정했을 때 17행·13행 witness만 허용됐으며, 6행과 finalize ACK가 없는 Compact는 계속 차단됐다. 원래 대기열의 정책 표시나 상태는 변경하지 않았다.

복사한 실패 청크 6개(원본과 복사본 SHA-256 6/6 일치)를 새 격리 코드로 오프라인 재처리했다. R11 incident 두 청크의 비정상 속도 행은 1,330·9,564개, replay 두 청크는 114·783개였다. R12 incident는 2,748개, replay는 226개였다. 로컬 후보는 행을 유지하고 표현 불가능한 속도 필드만 null로 처리하며, `anomalous-samples`에 원본 값·행 번호·원본 해시를 남긴다. 이것은 **청크별 실험 후보**일 뿐 전체 예선 finalize ACK 또는 전송 가능 패키지가 아니다.

운영 전송의 선행 단계는 다음과 같다.

1. 준비된 서버 `QualifyingWitnessRecovery`를 비운영 환경에서 실제 17행·13행 복사본과 안전차 행으로 검증한다. 현재 PC에서는 PHP 실행기를 찾지 못해 새 서버 테스트를 실행하지 못했다. 서버 소스는 운영에 배포되지 않았다.
   현재 연결 코드는 witness 수신 시점에 이미 승인된 공식 레이스만 찾는다. 승인 전 저장된 witness가 나중에 자동 연결되는 경로는 확인되지 않았으므로, 비운영 검증에서 승인 순서와 수신 순서를 모두 시험하고 필요하면 이 경로를 보완한다.
2. 배포 대상 서버 버전과 예상 영향(예선 전용 witness를 기존 승인 레이스의 격리된 예선 분류로만 연결, 레이스 결과 원본 유지)을 제시하고 **서버 배포 승인**을 받는다.
3. 운영 DB를 읽기 전용으로 조회하여 witness의 `body_sha256`·`witness_uid`·idempotency key, 메타데이터의 `chunk_uid`·`content_sha256`를 이 표의 manifest와 대조한다. R11 #152 및 R12의 정확한 공식 세션 ID, 기존 예선 분류·원본 연결 유무도 확인한다. 동일 원본이 이미 있으면 재전송하지 않는다.
4. 위 조회 결과와 영향을 보고 **R11 witness, R11 메타데이터 15개, R12 witness, R12 메타데이터 3개를 각각 명시적으로 승인**받은 뒤 선택한 항목만 전송한다. 구버전 대기열 전체 재시도나 운영 프로필 실행은 하지 않는다.
5. 각 HTTP ACK의 `status=STORED` 또는 `DUPLICATE`, 원본 ID·해시 및 재시작 후 SENT 상태를 확인한다. 예선 전용 witness의 HTTP 201은 `canonicalSessionId=null`이어도 저장 성공일 수 있다. 서버의 예선 분류는 별도 검증·승인 전까지 격리 상태로 둔다.

운영 관리자 화면에는 여전히 R11 공식 17명·R12 공식 13명과 예선 기록 없음이 표시된다. 목록을 읽던 중 0명 그룹의 삭제 링크를 잘못 열었으나 서버가 409로 중단했고, 뒤로 돌아가 해당 그룹과 두 공식 경기가 목록에 그대로 있음을 확인했다. 서버 해시 수준 중복 여부는 이 화면에서 확인할 수 없었다.
