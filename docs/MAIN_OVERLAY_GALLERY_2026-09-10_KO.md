## 구현
- ClientStatusWindow.xaml 및 .xaml.cs: 메인 화면과 창 크기.
- ClientStatusWindow.Gallery.cs: 목록, 체크, 기본/레이싱 선택, 현재 설정 동기화.
- OverlayGalleryPreview.cs: 실제 오버레이 컨트롤을 예시 데이터로 렌더링.
- App.xaml.cs: 디자인 선택을 기존 저장/실제 오버레이 반영에 연결. 저장 오류 시 이전 선택으로 복구.
- DrivingHudSettingsWindow.cs: 색상·글꼴·핸들 설정 유지. 메인에서 고른 디자인 보존.
- DemoSnapshotFactory.cs: 기존 편집용 페달 예시 생성 코드를 이동하여 목록에서도 재사용.
- OverlayWindow.xaml.cs: 이동한 예시 생성 함수 호출.
- 기존 체크 상태, 디자인, 색상, 글꼴, 핸들 범위는 서로 독립적으로 저장.

미리보기는 192 DPI로 한 번 렌더링한 정지 BitmapSource를 Freeze하여 표시한다.

색상·글꼴·핸들 범위가 바뀔 때만 예시를 재생성하며, 디자인 선택만 바꿀 때는 같은 이미지를 재사용한다.
