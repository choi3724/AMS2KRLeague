# 주행 계기판과 업데이트 후 재실행

- REQ-DRIVE-01: 업데이트 후 프로그램 자동 재실행. 상태창을 표시하되 게임 포커스를 가져오지 않음. 설치 성공과 실행 실패를 구분해 기록하고 기존 검증·복구 경로 유지.
- REQ-DRIVE-02: 브레이크(빨강)·악셀(초록)·클러치(파랑)·핸드브레이크(보라) 최근 10초 그래프와 현재 입력량. 속도 xxx km/h, 상단 '기어' 네모 테두리와 중앙 숫자는 각각 독립 패널. 위치·크기·표시 설정 저장, 편집 미리보기 지원.
- REQ-DRIVE-03: 프로그램 설정 메뉴에서 네 입력 색상과 속도/기어 글꼴 각각 변경·저장. 재시작 유지, 기본 위치 복원은 외형 설정 보존.
- REQ-DRIVE-04: 기존 읽기 전용 SHM의 로컬 차량 값만 사용. 알 수 없는 값/다른 관전 차량을 추정하지 않고 빈 값 표시. 세션/시점 불연속 시 그래프 초기화, 기록 수 제한. 원본·업로드 형식·모드 정책 변경 없음.
- REQ-DRIVE-06: 사용자 첨부 이미지를 실행 파일·상태창·설치 파일 아이콘으로 지정. 원본을 그대로 포함한 다중 해상도 ICO를 빌드 자원으로 사용.
- REQ-DRIVE-07: 그래프는 새 입력이 오른쪽에 등장하고 이전 기록이 왼쪽으로 연속 이동. 세 페달 곡선이 같은 영역에서 겹쳐 흐르고 핸드브레이크 선 유지. 편집 미리보기도 움직이며 실제 주행 값은 합성하지 않음.
- REQ-DRIVE-08: 하단 한글 범례를 제거하고 우측 입력 막대에 A(악셀), B(브레이크), C(클러치), H(핸드브레이크)를 순서대로 표시. 한글패치 0.7의 Pretendard Medium 원본 폰트를 앱에 포함하고 공통 HUD/상태창과 새 패널의 기본 글꼴로 사용. 속도/기어 사용자 글꼴 선택 유지.
- REQ-DRIVE-09: 제목은 '텔레메트리'만 표시. 선 그래프에 시간 기준 100ms 평활화와 둥근 곡선 연결을 적용해 급격한 톱니 모양 완화. 입력 막대·숫자·SHM/저장/전송 원본은 그대로 유지. 부드러운 곡선, 미확인 구간 단절, 좌측 이동을 검증하고 테스트 파일 갱신.
- REQ-RELEASE-045: 모든 구현/검증 완료 후 0.4.5 정식 Latest 릴리스. 공개 자산 감사, 버전·체크섬 확인.
